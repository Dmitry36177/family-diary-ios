# Семейный ежедневник для iPhone

Локальная версия на основе SwiftUI-клиента [Waffled](https://github.com/kevinpsites/waffled).

Пять экранов: **Сегодня, Календарь, Дети, Дом, Покупки**. Русский интерфейс в согласованном стиле бумажного ежедневника: кремовые страницы в линейку, книжный корешок, заголовки с засечками и закладки разделов. Иконка — семейный ежедневник с сердцем.

## Текущая версия

- Приложение открывается без регистрации и сервера.
- Записи, домашние дела, профили детей и покупки сохраняются на iPhone.
- Покупки разделены на продукты, товары детям, бытовую химию и товары для дома. Есть количество и отметка о покупке.
- Кнопка «Ребёнок» открывает профиль: имя, необязательные дата рождения и класс.
- В календаре выбор даты задаёт дату нового напоминания.
- Для домашних дел есть недельный график: несколько дней недели, время и ответственный профиль. Выполнение отмечается отдельно на каждую дату.
- В разделе детей можно вести расписание, домашние задания, прививки, приёмы, рост/вес, историю здоровья и развитие как записи с датой и заметкой.
- Время напоминания: в момент события, за 15 минут, за час, за день. Повтор: ежедневно, еженедельно, ежемесячно.
- Общего доступа, семейной синхронизации и удалённых push-уведомлений нет — это решение пользователя для текущей версии.

Локальные уведомления iOS могут срабатывать при закрытом приложении и без интернета. Нужно разрешить уведомления. iOS ограничивает число ожидающих уведомлений, поэтому приложение планирует до 58 ближайших и обновляет расписание при открытии и изменении записей. При большом числе повторений открывайте ежедневник регулярно. Удаление записи отменяет её будущие напоминания. Отметка повторяющегося дела завершает только выбранную дату; следующие повторения остаются в расписании.

Данные записываются атомарно в Application Support с защитой файлов iOS; сохраняется предыдущая копия. При ошибке записи интерфейс не сообщает об успешном сохранении. Данные не отправляются в сеть. Удаление приложения удалит его локальные данные; автоматическая синхронизация между устройствами отсутствует.

## Сборка

Требуются Xcode с iOS SDK и XcodeGen. Минимальная версия iOS — 18.0.

```sh
cd apps/ios
xcodegen generate
open Waffled.xcodeproj
```

В Xcode выберите схему **Waffled**, свой iPhone и свою команду в Signing & Capabilities. Идентификатор приложения: `ru.familydiary.ios`. Сторонние Swift-пакеты и сервер для этой сборки не нужны.

```sh
xcodebuild -project Waffled.xcodeproj -scheme Waffled \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
xcodebuild -project Waffled.xcodeproj -scheme Waffled \
  -destination 'platform=iOS Simulator,name=iPhone 17' CODE_SIGNING_ALLOWED=NO test
swift test
```

`TestsLocal` проверяет хранение, ошибки записи и повреждённые данные. `CoreTests` проверяет повторы, часовые пояса и ограничение уведомлений. `UITests` проверяет пять экранов, создание ребёнка и покупки, напоминание на выбранную дату, недельное расписание с ответственным, перезапуск и сохранение данных. Тесты интерфейса работают в отдельном временном хранилище Debug-сборки.

## Исходная кодовая база

Исходная точка: Waffled `44f3d629200f2fa019b581b9039f162fcc6e5170` (v0.15.3). Сохранены SwiftUI-точка входа и проект iOS; источник активных экранов и локальной логики — `apps/ios/Sources/Waffled/FamilyDiary`. Неиспользуемые исходные серверные и расширенные модули оригинала остаются в репозитории для истории, но не входят в локальную сборку iPhone. `apps/ios/project.yml` явно перечисляет её исходники и не подключает PowerSync или серверные возможности.
